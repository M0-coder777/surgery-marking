# 手术部位 3D 标记与三方核查系统 · 功能验证版本

用于验证「3D 人体模型手术标记 + 术前三方核对」的展示效果与交互流程。
**不含患者信息、不含 HIS 对接、不含编码映射、不含电子签名、不含手麻系统联动。**

## 运行

- **推荐**：`python -m http.server 8899` 后访问 `http://127.0.0.1:8899/`（模型自动加载）。
- **双击 `index.html` 也可以**：浏览器不允许网页自动读取本地文件，会弹出「选择 organs-bones.glb」提示，点按钮选择本目录 `models/organs-bones.glb`（或直接把该文件拖进页面）即可，功能完全一致。

无构建、无 CDN 依赖；Three.js 与 Draco 解码器均已本地化。

## 模型

两个内置模型，坐标系统一对齐（同为 Z-Anatomy 图谱原点，身高 1.696 m，两层包围盒中轴重合、身高差 13 mm）：

### ① 脏器层 `models/organs-bones.glb`（20.5 MB）

由 Z-Anatomy 中文解剖图谱（Startup.glb）提取的「骨骼 + 脏器」子集，**不含肌肉、血管神经、皮肤**：

- **1148 个可标记结构**（骨骼 626 / 脏器 137 / 脑与神经 385，中英文名），每个结构是独立可拾取、可整块选中的网格
- 约 161 万三角面片，真实米制尺寸，Draco 压缩，浏览器加载 + 解码约 2–4 秒
- 分类由提取器写入节点 extras（bone / viscera / brain），分组来自模型自带的中文解剖分类树（骨骼系统 / 内脏系统 → 胸廓、脊柱、消化、泌尿…）

### ② 部位层 `models/body-regions.glb`（0.72 MB）

由同一图谱自带的「人体分区」体系（`人体分区.g` 子树）提取的**体表分区皮面**，V0.5 新增：

- **250 个体表分区**（左右各 125，全中文命名，244 个唯一几何 / 23,105 面，左右共用几何靠节点镜像变换）
- 由 `src/regions.js` 的**归并表**归并为 **34 个体表部位**：头颈 2 · 胸 2 · 腹 9（临床九分区）· 背 2 · 会阴 1 · 上肢 8 · 下肢 10，全部区分左右
- 每个部位可**下钻**到其包含的图谱细分分区（如「左上臂」= 臂前区 / 臂后区 / 肘前区 / 肘窝 / 肱二头肌内外侧沟），细分分区同样可选中与标记
- 三态层级切换：**全部**（部位半透明外壳 + 脏器骨骼同屏）/ **仅部位** / **仅脏器**

## 演示路径（2 分钟走完）

1. 页面自带 5 个示例标记（胆囊切除范围 / 肝切口起点 / 脾穿刺点 / 右季肋区部位 / 左前臂引流部位）+ 1 条测量线，拖动旋转即可看到标记**不漂移**。
2. **体表部位（推荐先试）**：右侧「按部位」页签把「显示层级」切到**仅部位**，得到一个人形分区色块 → 在「体表部位」清单里单击「右季肋区 / 右上腹」即整块选中，或用工具栏「部位」工具直接在模型上点一下 → 「标记整个部位」一键成区。
3. **全身部位 + 左右**：34 个体表部位覆盖头颈 / 胸 / 腹 / 背 / 会阴 / 上肢 / 下肢，左右各自成条（「右上臂」「左上臂」是两条）；点条目右侧的「▸ 7」可展开该部位的图谱细分分区，细分分区也能单独选中标记。
4. **按结构**：同页签可搜索「肝」「股骨」「前臂前区」，或按体区分组浏览；悬停在模型上**整块预览**，单击选中并自动正对，「标记整个结构」一键成区。
5. **层级切换**：「全部 / 仅部位 / 仅脏器」三个按钮联动可见性、拾取目标、部位高亮与已有标记显隐（切到「仅脏器」时体表部位的标记一并隐藏，不留悬空标记）。
6. 工具栏「点标记」在结构表面点一下 → 自动解析所属结构；「区域标记」连续取 3 点以上 → 「闭合成区域」。
7. 左侧选好侧别 → 「提交三方核查」；顶栏切换身份完成三方核对；三方一致自动冻结（只读 + 校验码）。

## 关键设计

- **标记锚定**：点标记存 `{ meshId(结构id), faceIndex, bary:[u,v,w] }`；整块结构 / 体表部位 / 图谱细分分区标记只存 `{ regionKey }` 一个标识符，位置取分区质心。屏幕/世界坐标一律不入库，渲染时实时反算——这是"旋转缩放不漂移"的唯一原因。
- **结构即部位**：每个网格、每个体表部位、每个图谱细分分区都注册进同一份结构索引（名称 / 类别 / 体区分组 / 侧别 / 质心 / 包围盒），点击解析与列表选中共用一套标准。
- **部位层 = 数据驱动的归并表**：`src/regions.js` 里每个体表部位是一行数据（所属系统 / 侧别 / 包含的图谱分区规则），**不预切几何**。后期加部位 = 在表里加一行 + 补一条归并规则，模型不用重新导出。
- **两层模型**：脏器层与部位层是两个独立 GLB，坐标系统一（同为图谱原点）；部位层用半透明外壳材质（`opacity 0.24 / depthWrite false / renderOrder -2`）叠加在脏器层之上，既能看体表分区又能透视深层结构。
- **类别显隐 + 层级切换**：骨骼 / 脏器 / 脑与神经三类独立开关，另有「全部 / 仅部位 / 仅脏器」三态层级。两者都联动拾取列表、部位高亮缓存（置空失效重建）与已有标记的显隐，避免"悬空标记"。
- **体区分组**：优先用模型自带中文分类树（祖先链 + 结构名规则），未命中再按骨性标志几何兜底；侧别由结构重心 x 符号推断（+x = 患者左，面对患者视角），中轴骨归盆部与会阴。
- **结构高亮懒建**：整块高亮几何按需生成并缓存（自身几何变换到根坐标 + 法线微外扩）；体表部位的高亮是其成员几何的合并（Uint32 重基址索引），可见性变化后自动失效重建。
- **隐私机制**：`privacyAudit()` 在每次落盘/导出/导入前机械扫描禁用键，命中即阻断——把"不记录患者信息"从约定变成机制。

## 技术说明

- 无构建步骤，经典 `<script>` 加载（保证 `file://` 双击可用），全局命名空间 `window.SMK`。
- GLTF/DRACO 加载器由 three r159 官方 ESM 源码去除 import/export 后打包为经典脚本（`anatomy-loaders.js`），与全局 THREE 共享同一实例，无重复加载。
- `file://` 直开时浏览器禁止 fetch，加载器自动降级为「选择 / 拖入模型文件」，用 FileReader + `GLTFLoader.parse` 解析，功能一致。
- 模型原始命名左右成对重名（输尿管.l / 输尿管.r），加载时重写为场景唯一名，保证点锚定经 `getObjectByName` 反查时不错到另一侧。
- 相机控制为自实现（旋转/缩放/平移/双指捏合/视角预设补间）；渲染循环带暂停开关（静止省电）。
